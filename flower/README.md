# 程序化像素草地

打开 flower.tscn，选中 ColorRect，即可在编辑器预览。F6 运行当前场景。
尺寸为 640×384。所有内容都在 flower 文件夹内；修改前文件在 backup 中。

## 调参

Material → Shader Parameters：

- Pixel Size：逻辑像素格大小，越大越粗。默认 2。
- Patch Size：大片颜色变化的尺度，越大色块越大。默认 150。
- Dark Grass / Light Grass：最深和最浅的草地色。
- Color Steps：大色块颜色层级，默认 5；越少分层越明显。
- Patch Contrast：大片深浅变化的对比度。
- Detail Strength：细斑驳强度，建议保持较低。
- Grass Density：草簇出现概率的上限，受连续噪声调制，并非草像素的覆盖率。
- Grass Contrast：草簇与地面的明暗差异。
- Random Seed：换一片地面，分布不随时间闪烁。
- Debug View：0 最终效果；1 仅大色块；2 草簇遮罩；3 连续噪声。

## 原理

世界坐标 → 统一像素网格 → 连续噪声和颜色分级 → 轻微斑驳 → 成簇草点。
连续噪声全部采用二维柏林噪声（Perlin Noise）：大色块使用三层叠加，坐标扰动、细斑驳和草簇分布调制也使用柏林噪声。
噪声直接在 Shader 中计算，不需要创建 NoiseTexture2D 或 FastNoiseLite。草簇位置、形状与出现概率的离散随机选择仍使用哈希函数。
所有地块使用同一套世界坐标和相同材质参数，像素格与噪声不会在瓦片边界重新开始。
材质保留输入 Alpha；草地颜色由程序完全生成，没有花、树或河流。

## 使用提醒

如果编辑器提示磁盘文件改变，请重新加载磁盘版本，避免旧的未保存场景覆盖新内容。
草簇使用少量模板随机摆放，像素大小过大时会更像符号，建议先使用 1 或 2。
世界坐标采样适合静态地面；移动地块会露出世界坐标中不同的图案。
