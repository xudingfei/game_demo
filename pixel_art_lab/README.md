# Pixel Art Lab / 六足火炮机甲

独立 Godot 4 示例。打开 `res://pixel_art_lab/pixel_art_demo.tscn`，按 **F6 运行当前场景**。界面在运行时创建，编辑器内有启动提示。项目主场景不变。

左侧显示原图，右侧显示实时像素风格。默认使用 imagegen 生成的无粗黑描边平面机甲 PNG：内部以蓝色装甲、橙色护板和灰蓝关节等色块区分结构，保留平视侧面、水平朝右长炮管与透明背景。去掉原素材的粗黑轮廓，外描边由 Shader 统一生成，避免原图线稿经调色板量化后与新描边叠加。可以点击“选择自己的图片”加载 PNG、JPEG 或 WebP，推荐透明背景 PNG。

## 可调参数

| 参数 | 范围 | 含义 |
| --- | --- | --- |
| 像素格边长 | 1～24 | 以工作图片像素为单位；数值小更细，数值大更粗 |
| 主体颜色数量 | 2～32 | 从原图提取的调色板容量，主体像素映射到其中最近的颜色 |
| 外描边粗细 | 0～3 格 | 0 关闭；格子大小与像素格边长相同 |
| 描边颜色 | 自选不透明颜色 | 描边用色不计入主体颜色数量 |

主体实际可见颜色可能少于调色板容量，例如原图本来只有几种颜色，或采样时某些小区域消失。透明背景不计为一种颜色。像素格和轮廓形状是实时更新的，拖动颜色数量会延迟 0.18 秒重新提取调色板。

## 流程

1. 加载图片。超过 1024 像素的最长边会等比缩小，界面显示处理后的工作尺寸。
2. 为图片四周增加 96 像素透明留白，供外描边扩展；原图和结果使用同样留白，方便对照。
3. CPU 从小尺寸样本提取调色板：按颜色跨度和样本数量选择一组，沿跨度最大的 RGB 通道排序并从中间分开，重复直到达到指定数量；每组平均色成为一个候选颜色。这是中位切分的变体，只在换图或改颜色数量时运行。
4. Shader 把同一格的 UV 映射到格子中心，读取该位置颜色。透明度小于 0.5 的格子判为空，其余判为实体，因此柔和半透明边缘会变成硬边缘。
5. 实体格查找最近的调色板颜色，距离为加权 RGB 差值平方。这是低成本近似，不是感知色差算法。
6. 空格检查周围最多 3 格的实体像素，绘制方形邻域外描边。保留原图内部已有线条，但不会自动生成内部线稿。

## 使用限制

- 无透明背景的照片或 JPEG 会把背景也一起转换，外描边会沿整张图片边框生成；不包含自动抠图。
- 这是风格转换，不理解机甲关节、液压管线等结构。像素格过大可能导致细节消失，需要手工修整。
- 角色在屏幕上的显示尺寸过小时，即便调小像素格，也看不到所有细节。
- 主体调色板查询最多 32 次；透明像素描边最多检查 48 个邻格（3 格描边），大尺寸满屏使用时应控制成本。
- `pixel_art.gdshader` 单独挂材质时需要指定一张 32×1 调色板纹理及有效颜色数量。示例脚本自动生成这些资源并处理透明留白。
- 本例不覆盖原图、不更改项目主场景、不包含导出图片功能。
