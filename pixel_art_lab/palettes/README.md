# 自然低饱和 32 色

原创项目调色板，包含 8 个色组，每组 4 档明度。用于素材固有色，最终光照可以产生额外颜色。

## 文件

- `natural_32.png`：32×1、不透明 RGB 调色板纹理。按上表逐行、由左到右排列。
- `natural_32_preview.png`：带色值的预览色卡。
- `natural_32.hex`：每行一个十六进制色值。
- `natural_32.gpl`：GIMP Palette 文件，可导入支持该格式的绘图工具。

## 使用建议

- 机甲优先使用灰蓝、石灰、陶土；草地使用苔绿和草木；水面使用水色和灰蓝。
- 外描边可以统一使用 #283234；远景可以弱化或取消描边。
- 这是共享基础调色板，不要求每个素材用满 32 色。
- 四档明度不是要求把固定光照画进素材，可以用于不同部件固有色。
- 在 Godot 中作为 palette_texture 使用，过滤选 Nearest、关闭 Mipmaps，有效颜色数量设为 32。不要把预览色卡作为调色板纹理。
- 当前演示脚本会自动提取并覆盖调色板；本次只保存色卡，尚未把演示切换为固定调色板模式。
