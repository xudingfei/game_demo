# 河流实验室

在 Godot 文件系统中打开 `res://river_lab/river_demo.tscn`，按 F6（运行当前场景）。
场景运行后右侧调整水位、岸线宽度、水色、流速、扭曲和焦散。勾选自动涨水可以观察岸线移动。
演示界面在运行时创建，编辑器内请按 F6 查看。想在编辑器内直接看河流，请打开 river_surface.tscn。
river_surface.tscn 也可以实例化到其他 2D 场景，选择 RiverSurface 的 Material → Shader Parameters 调参。
暂停动画后仍然可以手动调参。下拉菜单可查看原图、高度图、水域遮罩、水深和岸线。

## 文件

- river_demo.tscn：独立演示入口，不修改项目主场景。
- river_demo.gd：运行时构建教学界面，传递参数和动画时间。
- river.gdshader：每个片段计算水域、颜色、岸线、扭曲和焦散。
- river_material.tres：可在检查器直接调整的材质。
- river_surface.tscn / river_surface.gd：可复用的 Sprite2D 河流及其动画时钟。
- assets/riverbed.png：480×300 原创像素河床。
- assets/height.png：对应的高度数据，黑低白高。
- assets/noise.png：可平铺的二维采样偏移。
- assets/caustics.png：可平铺的亮纹。
- generate_assets.py：仅依赖 Python 标准库的贴图生成脚本。

## 学习顺序

1. 原图仅提供颜色。切换高度图，看到每个位置对应的高度数据。
2. 水域条件是 height <= water_level。把水位从 0.2 拖到 0.75，观察浅滩和岛屿。
3. 水深是 max(water_level - height, 0)，控制水色和折射幅度。
4. 岸线检测水域内部是否邻接陆地，不使用原图透明边界。
5. 移动焦散贴图采样位置，制造流动亮纹。
6. 用噪声偏移河床取色位置。偏移越界或落到岸上时限制采样。

## 替换自己的素材

原图与高度图必须位置对齐，建议尺寸相同。高度图不声明 source_color，因为它是数据。
本演示整幅都是地形，没有透明无效区；如果换透明图片，需要额外遮罩排除无效区域。
岸线宽度和扭曲以原图纹理像素为单位，窗口缩放后显示大小随之变化。
0 表示最低地面，1 表示最高地面；这不是米。所有低于水位的区域同时进水，不模拟连通性、水量和流体。
流动方向是统一的装饰性纹理滚动，不会沿弯曲河道自动转向。
这是一套独立的学习实现，并非参考视频作者源码，也不是其等距美术资源的复刻。

## 山峰如何复用

积雪：step(snow_level, height)；水淹山脚：现有水域判断。
坡面明暗还需要法线；山峰投影还需要遮挡计算，不能仅用高度阈值代替。
