# 像素倒影水面 / Kingdom Water Lab

独立的 Godot 4 示例，研究《王国》风格水面的镜像倒影和横向波纹。风景由代码原创绘制，没有使用原作素材；并非《王国：两位君主》的官方实现。

## 打开

打开 `res://kingdom_water_lab/kingdom_water_demo.tscn`，按 **F6（运行当前场景）**。界面和风景在运行时创建，因此编辑器中的根 Control 是空白的。无需改变项目主场景。原来的 `coast_lab` 独立保留。

## 文件

- `kingdom_water_demo.tscn`：独立入口。
- `kingdom_water_demo.gd`：建立视口、绘制顺序和调节面板。
- `scenery.gd`：树木、山、月亮、小屋、暖灯与动态云。
- `kingdom_water.gdshader`：镜像采样、波纹扰动、水色和亮纹。

## 渲染顺序

1. 在固定 800×600 的 SubViewport 中绘制风景，水岸高度为 340。
2. BackBufferCopy 复制已经绘制好的风景，作为着色器的 `hint_screen_texture`。
3. ColorRect 覆盖水岸以下区域。每个水面像素采样水岸上方等距离的位置：`reflected_y = 2 × shoreline - current_y`。代码中使用归一化坐标，`shoreline = 340 / 600`。
4. 两层不同尺寸和速度的平滑值噪声沿指定水流方向传播，控制倒影沿水流轴局部晃动；横向细长的水纹造型保留。此处使用值噪声，并非柏林梯度噪声，也没有流体模拟。
5. 倒影混合水体底色，随远离岸线略微减弱；叠加少量横向亮纹。
6. 最终视口纹理以最近邻方式显示。调节面板在视口之外，不会被倒映。

该视口每帧生成场景图像，供动态倒影读取。没有湿沙历史缓存、反馈循环或水位模拟。水面最终 alpha 为 1，水色与倒影在 shader 内混合。

## 参数

| 参数 | 作用 |
| --- | --- |
| 波速 | 控制噪声移动速度，0 为静止波纹 |
| 水流方向 | 屏幕空间角度：0°向右、90°向下、180°向左、270°向上 |
| 波幅 | 倒影采样位置偏移的强度，0 可查看未扰动镜像 |
| 倒影强度 | 越高越接近风景倒影，越低越接近水体底色 |
| 像素大小 | 倒影与水纹采样的格子大小，单位为内部视口像素 |
| 亮纹强度 | 少量高亮水纹的叠加强度 |
| 水体底色 | 影响整体水色 |

脚本按 `flow_offset += direction × speed × 24 × delta` 累计位移，再传给着色器。调节波速不会跳到另一个历史时间；波速为 0 时波纹停止，岸上云朵等动画仍继续，暂停按钮会同时暂停两者。像素大小仅改变水面，不会重画岸上的素材。

## 倒影怎样顺着水流晃动

1. 将水流角度转换为单位向量：`direction = (cos(angle), sin(angle))`。
2. 使用 `p - flow_offset` 采样噪声，使噪声图案朝水流方向移动；细水纹使用 1.55 倍位移，增加层次。
3. 将噪声转为正负偏移量，乘以水流方向和波幅。每个位置的偏移不同，倒影因此产生局部摆动。此处是沿水流轴来回摆动，水纹本身持续顺流传播。
4. 按照偏移后的镜像坐标读取风景。偏移始终限制在一定幅度内，不累计搬动整幅倒影。
5. 岸边的偏移幅度渐变到 0，使倒影和岸边物体衔接。

水流方向是屏幕空间方向，不是三维水面中的真实流向。该版本由脚本驱动 `flow_offset`；将 shader 单独移到其他场景时，也需要更新这个参数。`wave_speed` 由演示脚本读取用于累计位移，单独修改它不会自动产生动画。

## 使用范围

适合横版场景、固定水平岸线的池塘或湖面。俯视地图中的弯曲海岸不能直接照搬这条水平镜像公式。若将 TileMapLayer 放入此视口、安排在 BackBufferCopy 之前绘制，它也能出现在倒影里。
